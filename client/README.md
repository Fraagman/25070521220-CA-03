# CARNAGE OPTIX // Client Frontend
**React 19 + TypeScript + Vite + Tailwind CSS**

The brutal & gore-themed client application for CARNAGE OPTIX sunglasses store.

### Scripts
- `npm run dev` - Launch local Vite dev server on `http://localhost:5173` with proxy to backend (`http://127.0.0.1:5000`)
- `npm run build` - Typecheck and build production assets into `dist/`
- `npm run typecheck` - Run TypeScript compiler checks (`tsc --noEmit`)
- `npm run lint` - Run ESLint
- `npm test` - Run Vitest unit tests
